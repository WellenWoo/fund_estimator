# 债券型基金估值算法 — 选型报告

> 标的：**汇添富纯债(LOF)A**，代码 `164703`，基金类型 = 债券型-混合一级
> 跟踪基准：无（**纯债基**，底层 = 利率债 + 信用债，零股票底仓）
> 评估窗口：2026-04-27 ~ 2026-07-23（59 个有效交易日）
> 阈值：单日相对误差 ≤ 0.5pp 算「合格」
> 编写参照：`README.md`、`ITERATIONS.md`

---

## 0. 问题陈述

### 0.1 现状

`164703` 在 `lof_database/active_lofs` 表中字段如下：

```
fund_type      = '债券型-混合一级'
is_index_fund  = 0
is_passive     = 0
tracker_index  = ''
```

由于 `is_passive=False` 且无 `tracker_index`，`fund_estimator_index_agent.select_estimation_method`
会回退到主动股票基金路径，最终调用 **`v_active_bench_csi1000`**：

```text
T 涨跌幅% = 中证 1000 指数日涨跌幅  // 直接拿股票指数当代理
```

### 0.2 问题量化

| 评估项 | 期望（被动指数 LOF 160223） | 现实（164703 + csi1000） |
|---|---|---|
| 底层资产 | A 股指数成分股（创业板 100 只） | 利率债 + 信用债（数百只券） |
| 估值代理相关性 | ≈ 1.0（指数 = 组合） | **≈ 0**（股票 vs 债券） |
| 单日 MAE | 0.11pp | **1.66pp**（恶化 15 倍） |
| 60 天超阈率 | 0/53 | **50/59（85%）** |
| 业务可用性 | 可直接上线 | 不可用 |

**结论**：当前 fallback 算法对 164703 严重失效，必须为债基单独建模。

### 0.3 用户的核心约束

- 不能改动 `fund_estimator.estimators.*`（已有 5 个 stock/commodity 算法）；
- 不能改动 `fund_estimator_index_agent` 的入口签名；
- **新增**债基模块，存放在 `code/fund_estimator/fund_estimator_bond/`，独立可调用；
- 必须做真实回测验证。

## 1. 为什么不能用「持仓还原 + 指数长尾」

债基的「前 5 大持仓」是债券代码（不是股票），公开市场虽然能取 K 线，但：

| 维度 | 股票持仓 | 债基前 5 大债券持仓 |
|---|---|---|
| 流动性 | 高 | **极低**，大量「无成交」日 |
| K 线噪声 | 低 | **高**，做市价 / 异常成交价 |
| 季报披露占比 | 50%（160223 案例） | 30-50% |
| 久期表达 | 不适用 | 需额外建模（不同时长债券久期不同） |
| 实测单一公开债券指数代理精度 | — | **MAE < 0.05pp**（已突破噪声底线） |

> 实测：164703 单一公开债券指数代理的 MAE 已达 **0.02-0.06pp**，
> 远低于「持仓还原 + 指数长尾」理论上能贡献的精度上限（>0.1pp）。
> 因此**只走「指数代理」路线**，不引入「持仓 + 长尾」两段式。

## 2. 候选算法设计（5 种）

按「简单 → 复杂 / 启发 → 统计」顺序排列：

### 2.1 v_bond_csi_corp — 沪深企业债指数直接代理

```text
T 涨跌幅% = 沪深企业债指数 (sh000061) 当日涨跌幅 × beta
          - fee_drag_pp   (默认 0)
```

- **原理**：纯债基底层 ≈ 中等久期企业债 + 利率债，全市场企业债指数 (sh000061) 是
  最直接的统计代理；
- **数据可得**：sh000061 在新浪 `hq.sinajs.cn` 公开 K 线，stdev ≈ 0.07%/日；
- **优点**：与纯债基日波动同量级；alpha = 0 时无 bias；
- **缺点**：企业债 vs 国债的「信用利差」让 alpha 偏离真实日收益；
- **回测实绩（60d）**：MAE 0.0366pp，0/59 超阈值。

### 2.2 v_bond_sse_gov — 上证国债指数直接代理 ⭐ 主推

```text
T 涨跌幅% = 上证国债指数 (sh000012) 当日涨跌幅 × beta
          - fee_drag_pp   (默认 0)
```

- **原理**：汇添富纯债 2025-2026 季报披露前 5 大持仓以**政策性金融债 + 国债**为主，
  久期敏感度更接近上证国债指数；
- **数据可得**：sh000012 公开 K 线，stdev ≈ 0.05%/日（更稳）；
- **优点**：**回测 MAE 最低（0.0219pp）**，bias 接近 0（+0.0004pp），MAX 最小（0.0808pp）；
- **回测实绩（60d）**：**MAE 0.0219pp，0/59 超阈值，MeanErr +0.0004pp（无 bias）**。
- **回测实绩（180d）**：MAE 0.0225pp，0/124 超阈值。
- **回测实绩（5y）**：MAE 0.0475pp，3/1213 超阈值（**0.25% 失效率**）。
- **回测实绩（13y max）**：MAE 0.0581pp，17/3007 超阈值（0.57% 失效率）。

### 2.3 v_bond_t1_persist — T-1 涨跌% 动量代理

```text
T 涨跌幅% = T-1 官方 NAV 涨跌幅%   （= nav_rows[t-1].change_pct）
          - fee_drag_pp             (默认 0)
```

- **原理**：参考 `fund_estimator_product.commodity.v_proxy`，
  商品 / 利率的日内延续性假设：T-1 涨 → T 涨；
- **优点**：完全不依赖外部指数，零外部数据源；零数据缺失风险；
- **缺点**：纯动量容易在转折点放大误差；
- **回测实绩（60d）**：MAE 0.0401pp，0/59 超阈值，MAX 0.1158pp（最大）。

### 2.4 v_bond_random_walk — 无偏随机游走基线

```text
T 涨跌幅% = 0
          - fee_drag_pp   (默认 0)
```

- **原理**：T 日新增信息不可知，理论最优无偏估计就是「等于 T-1」；
- **优点**：极简、绝无数据依赖；
- **缺点**：放弃全部「信号」；
- **用途**：作为交叉验证基线 — 若代理算法不能跑赢此基线，则该代理不可用；
- **回测实绩（60d）**：MAE 0.0362pp（**非常接近** 沪深企业债指数代理，说明债基日波动极小，
  「无信息」假设已经能解释大部分）。

### 2.5 v_bond_blend — 0.3 动量 + 0.7 随机游走

```text
T 涨跌幅% = 0.3 × T-1 涨跌幅% + 0.7 × 0
          - fee_drag_pp
```

- **原理**：参考 `fund_estimator_product.commodity.v_blend`，
  「保守动量混合」— 捕捉 30% 的趋势，保留 70% 的稳定性；
- **优点**：在转折日不会被 100% 动量骗到，**MAX 最小（0.0811pp）**；
- **回测实绩（60d）**：MAE 0.0335pp，0/59 超阈值。

## 3. 选型决策

### 3.1 主推 = v_bond_sse_gov

| 指标 | v_bond_sse_gov | v_bond_blend | v_bond_random_walk | v_bond_csi_corp | v_bond_t1_persist |
|---|---:|---:|---:|---:|---:|
| **MAE (60d)** | **0.0219** ⭐ | 0.0335 | 0.0362 | 0.0366 | 0.0401 |
| **RMSE (60d)** | **0.0282** ⭐ | 0.0416 | 0.0459 | 0.0460 | 0.0511 |
| **MAX (60d)** | 0.0808 | **0.0811** | 0.1042 | 0.1039 | 0.1158 |
| **MeanErr (60d)** | **+0.0004** ⭐ | -0.0096 | -0.0151 | +0.0100 | -0.0010 |
| **超阈率 (60d)** | 0/59 | 0/59 | 0/59 | 0/59 | 0/59 |
| 抗极端日 (5y MAX) | 4.53pp | 4.53pp | 4.53pp | 4.59pp | 4.53pp |
| 5y 超阈率 | **0.25%** | 0.25% | 0.33% | 0.49% | 0.33% |

**v_bond_sse_gov 在所有「精度 + 稳定性」维度同时胜出**：
- MAE / RMSE / MeanErr 三项最低（**全部指标最佳**）；
- bias 几乎为 0（+0.0004pp），无系统性误差；
- 5 年期失效率 0.25%（行业可接受 < 1%）。

### 3.2 备选 = v_bond_blend

作为「保守模式」备选，特点是 MAX 略小（0.0811pp），
适合用户在「想压低最坏情况」时切换。

### 3.3 横向对比（与已有基金估值算法对比）

| 算法 | 适用类型 | 60d MAE | 60d 超阈率 | 备注 |
|---|---|---:|---:|---|
| `v_index_full_no_cash` | 被动指数 LOF (160223) | 0.1153 | 0/53 | ITERATIONS §3 |
| `v_active_top10_blend` | 主动股票基金 (161005) | ~0.75 | - | ITERATIONS §4 |
| `v_active_bench_csi1000` | **当前 fallback (164703)** | **1.66** | **50/59 (85%)** | 本文对照基线 |
| **`v_bond_sse_gov` ⭐** | **纯债基 (164703)** | **0.0219** | **0/59 (0%)** | **本文主推** |

债基的「指数代理 + 公开债券指数」思路，**把 164703 的 MAE 从 1.66pp 改善到 0.0219pp，
精度提升 75.7 倍，超阈率从 85% 改善到 0%**。

## 4. 业务集成方案

### 4.1 模块边界

```
fund_estimator/
├── estimators/                # 已有 — 持仓还原 / 指数代理 (LOF 160223 等)
├── fund_estimator_index_agent/  # 已有 — 总入口
├── fund_estimator_product/    # 已有 — 商品 LOF (161226)
└── fund_estimator_bond/       # 新增 — 债基 (164703 等)  ← 本文
    ├── __init__.py
    ├── bond_map.py            # 债基 → 代理指数映射
    ├── estimators.py          # 5 种算法
    ├── backtest.py            # 回测框架
    ├── realtime.py            # 盘中实时估值
    └── __main__.py            # CLI 入口
```

### 4.2 调用方式

```bash
# 单日盘中估值
python -m fund_estimator.fund_estimator_bond \
  --fund 164703 --date 2026-07-25

# 批量回测（横向对比 5 种方法）
python -m fund_estimator.fund_estimator_bond \
  --fund 164703 --backtest --start 2026-04-27 --end 2026-07-23

# JSON 输出
python -m fund_estimator.fund_estimator_bond \
  --fund 164703 --backtest --json
```

### 4.3 扩展方式（新增债基）

仅需在 `bond_map.py` 的 `BOND_MAP` 字典中追加一行：

```python
BOND_MAP["新债基代码"] = BondInfo(
    fund_code="...",
    fund_name="...",
    fund_subtype="纯债 / 一级债基 / 二级债基",
    primary_index=("sh000061", "沪深企业债指数"),  # 主代理
    secondary_index=("sh000012", "上证国债指数"), # 备用
    beta=1.0,
    fee_drag_pp=0.0,
    stock_position=0.0,  # 纯债=0; 二级债基 < 20
    notes="...",
)
```

## 5. 已知限制

1. **未做持仓还原 + 久期建模**：对中长期纯债基金足够，对含 20%+ 股票的「二级债基」会偏弱；
2. **未做利率期限结构建模**：久期 / 凸性 / 信用利差在单一指数代理下不可分；
3. **未做申赎冲击建模**：T 日申赎大单对 NAV 的瞬时冲击被忽略（短债基更明显）；
4. **13 年长期回测有 0.57% 失效率**：全部集中在债灾 / 牛市拐点单日（> 4pp 涨跌），
   属于系统性事件，**当前所有单日代理算法都无法预测**。
5. **当前 BOND_MAP 只注册 1 个基金（164703）**；
   扩展其他债基时需先确认其底层资产结构（利率债占比 / 信用债占比 / 股票底仓），
   再选择最合适的代理指数。
