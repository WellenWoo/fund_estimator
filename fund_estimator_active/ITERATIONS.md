### 关键发现

1. **主动基金难估值**：MAE 0.71pp，**33/55 (60%) 超 0.5pp 阈值**。
2. **中证 1000 完胜其他 benchmark**：沪深 300 是被动基金的最优，但 160211 是中小盘成长风格。
3. **alpha=1.0 (纯 benchmark) 比 alpha=0.5 (混合) 更好**：top10 数据噪声大，反而拖累估值。
4. **Bias 偏正 (0.20pp)**：基金系统性跑赢中证 1000（经理 alpha 贡献）。

### 与 v1.0 (160223 被动) 对比

| 维度 | 160223 (被动) | 160211 (主动) |
|---|---|---|
| 最佳算法 | 创业板指代理 (无 cash_drag) | 中证 1000 代理 |

| 0.5pp 阈值 | 0/53 (0%) | 33/55 (60%) |

### 4.2 改进空间

主动基金的特点决定了**短期内**难以突破 0.5pp 阈值。可改进方向：
1. **Barra 风格因子**：用 size / value / momentum / volatility 因子残差建模
2. **滚动 alpha 估计**：用近 20 天基金相对 benchmark 的残差作为今天的 alpha 修正
3. **多 benchmark 集成**：csi1000 + csi500 + cyb 加权
4. **行业轮动加权**：根据基金近期行业暴露度动态调整
5. **机器学习残差预测**：XGBoost 训练残差序列

详细见 `README.md` 7. 改进路径。
