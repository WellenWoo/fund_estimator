# JD 9积分兑换免费小保养 - 自动抢脚本

## 场景

每天 10:00 在京东养车频道抢 **"9积分兑换免费小保养"**。脚本自动做两件事：
1. 勾选 "9积分兑换" 单选框
2. 点击 "兑换" 按钮

10:00 前按钮是灰色的 "已抢完 每天上午10点补充库存"，10:00 才会激活。本脚本会等到 10:00 准点触发，自动处理按钮文案/样式的变化。

---

## 方案一：油猴脚本（强烈推荐 ✅）

**优点**：装一次，每天自动跑，不用每天粘代码，电脑开不开都没事（只要浏览器开 + 该页签在）。

### 步骤

1. Chrome / Edge / Firefox 安装 **Tampermonkey** 插件
   - 商店搜 "Tampermonkey"，或直接访问 https://www.tampermonkey.net/
2. 安装好后，浏览器右上角出现油猴图标，点它 → **"添加新脚本"**
3. 把 `jd-9points-autoclick.user.js` 的全部内容粘贴进去，Ctrl + S 保存
4. 打开目标页面：
   ```
   https://pro.m.jd.com/mall/active/3Rcw1NV6pjiUBpznNHooXjPNAicD/index.html?babelChannel=ttt1&categoryId=331801&serviceType=jdxc&sourceCode=liebiaoye&skuId=100240903791&preventPV=1&forceCurrentView=1
   ```
5. F12 控制台能看到 `[JD-9积分] 脚本已加载…` 就说明跑起来了
6. **每天 10:00 前 5 秒把标签页切回来挂着**（别最小化、别切走、别锁屏——锁屏会暂停 JS 计时）

### 调时间

脚本默认触发窗口是 `10:00:00 ~ 10:00:07`（7秒容错）。如果想更激进，改成 `TRIGGER_WINDOW = 3`；想保险一点就 `15`。

## 方案二：控制台版（不想装插件）

适合临时用一两次，或者在别人电脑上跑。

### 步骤

1. 打开目标页面
2. F12 → **Console** 面板
3. 粘贴 `jd-9points-console.js` 全部内容，回车
4. 看到 `[JD-9积分] 控制台版已启动` 就 OK
5. 标签页保持打开，10:00 自动执行

⚠️ **限制**：
- 标签页刷新了要重新粘
- 浏览器关了就没了
- 只能当天用

---

## 原理说明

| 步骤 | 怎么做的 |
|------|----------|
| 定时 | `setInterval(100ms)` 检查系统时间，到 `10:00:00` 触发 |
| 找 radio | 从含文字 "9积分兑换" 的元素向上爬 2~8 层，找最近的 `van-radio` / `input[type=radio]` / `[role=radio]` / 可点击卡片 |
| 找按钮 | 匹配关键词 `立即兑换 / 兑换 / 去兑换` 等，过滤掉 `disabled` / `pointer-events:none` / `opacity:0` |
| 点击 | `el.click()` + 派发 `mousedown/mouseup/click/pointerdown/pointerup` 多种事件，兼容移动端和 Vant 框架 |
| 重试 | 单次操作最多 20 次重试（间隔 150ms），给页面响应留时间 |

---

## 注意事项 ⚠️

1. **页面要一直开着**。浏览器 JS 在标签页休眠/最小化时会被节流甚至暂停。建议：
   - 提前 1~2 分钟把页面切到前台
   - 用 [Keep Awake](https://chrome.google.com/webstore/detail/keep-awake/bkihpmhdlhcofnfefkdjaljiccpdhhhk) 这类插件防止电脑息屏
2. **不要刷新页面**（油猴版没关系，控制台版刷新会失效）
3. 脚本不会帮你登录，**第一次必须人工登录并保持登录态**
4. 兑换成功后可能还有"确认兑换 / 支付 0 元"弹窗，脚本会触发原生通知提醒你，但最后一步建议手动确认

## 调试

| 日志 | 含义 |
|------|------|
| `脚本已加载，等待每天 10:00 自动触发` | 启动成功 |

| `⏰ 10:00 到了，开始执行` | 触发 |
| `✅ 已勾选 9积分兑换` | 第一步成功 |
| `✅ 已点击兑换按钮` | 第二步成功 |
| `❌ 未找到 9积分兑换 选项` | 选择器失效，可能是京东改版 |
